# เอกสารวิเคราะห์ความเสี่ยงและความปลอดภัย (Risk & Safety Assessment)
**โครงการ:** RUAYRUAY GROUP — TikTok Affiliate Showcase & Auto-Video Studio  
**วันที่บันทึก:** 2026-10-29  

---

## 1. ความเสี่ยงด้านแพลตฟอร์มและบัญชีผู้ใช้ (Platform & Account Risks)

> [!WARNING]
> การใช้ Session Cookie เรียก Showcase API และการควบคุม DOM บนหน้าเว็บ TikTok Studio, Meta AI และ Google Flow เป็นการจำลองการทำงานของผู้ใช้ (Browser Automation) ซึ่งอาจมีความเสี่ยงต่อเงื่อนไขการให้บริการของแพลตฟอร์ม

### 1.1 ความเสี่ยงต่อบัญชี TikTok & TikTok Shop
1. **การหมดอายุของ Session Cookie:**
   - **ความเสี่ยง:** Cookie มีอายุจำกัด หรือถูกยกเลิกเมื่อมีการ Logout/Login จากอุปกรณ์อื่น
   - **มาตรการป้องกัน:** ระบบจะตรวจจับ HTTP 401/403 และแจ้งเตือนให้ผู้ใช้ล็อกอินใหม่ทันที ไม่ส่ง Request ซ้ำให้เกิดปัญหา
2. **การตรวจจับ Bot / Captcha ใน TikTok Studio:**
   - **ความเสี่ยง:** หากมีการสั่งคลิกหรือพิมพ์เร็วผิดธรรมชาติ อาจกระตุ้นระบบ Anti-Bot หรือ Bdturing verification
   - **มาตรการป้องกัน:**
     - ไม่ใช้เทคนิคหลบเลี่ยงการตรวจจับ แต่ใช้การจำลอง Human-like Timing (เว้นจังหวะ 400–1200ms)
     - หากตรวจพบหน้า Captcha หรือหน้าต่างยืนยันตัวตน **ระบบจะสั่งหยุดคิวทันที (Hard Stop)** และแจ้งเตือนผู้ใช้ ไม่พยายามฝืนคลิกต่อ
3. **การถูกจำกัดการมองเห็น (Shadowban / Rate Limit):**
   - **ความเสี่ยง:** การโพสต์คลิปที่มีเนื้อหาหรือสไตล์ซ้ำกันถี่เกินไป หรือโพสต์จำนวนมากผิดปกติ
   - **มาตรการป้องกัน:**
     - ใช้โหมดตรวจก่อนโพสต์ (Review Mode - โหมด A) เป็นค่าเริ่มต้น
     - ระบบบังคับเว้นระยะห่างระหว่างคลิป (Interval Delay)
     - ระบบ Loop บังคับให้ DeepSeek คิดบทพูดและ Hook ใหม่ทุกรอบ ห้ามโพสต์คลิปเดิมซ้ำ

### 1.2 ความเสี่ยงต่อบัญชี Meta AI & Google Flow
1. **การถูกระงับสิทธิ์ชั่วคราวจากการส่งคำสั่งถี่:**
   - **ความเสี่ยง:** การส่งคำสั่งสร้างวิดีโอติดต่อกันโดยไม่รอผล
   - **มาตรการป้องกัน:** ระบบใช้ Job Lock แท็บเดียวทีละงาน รอจนวิดีโอเรนเดอร์และดาวน์โหลดเสร็จสมบูรณ์ก่อนส่งงานถัดไป
2. **การถูกปฏิเสธ Prompt (Prompt Moderation):**
   - **ความเสี่ยง:** สินค้าบางประเภท (อาหารเสริม, สกินแคร์, อุปกรณ์การแพทย์) อาจโดนระบบคัดกรองคำของ Meta AI ปฏิเสธ
   - **มาตรการป้องกัน:** หาก Meta AI ปฏิเสธ ระบบจะบันทึกสถานะว่า **"ข้าม (Skipped)"** พร้อมระบุเหตุผล และไม่ส่งซ้ำเพื่อไม่ให้เปลืองโควตา

## 2. ความเสี่ยงด้านความถูกต้องของเนื้อหา (Content & Legal Compliance)

1. **การเคลมสรรพคุณเกินจริง (Misleading Advertising):**
   - **ข้อกำหนด:** พระราชบัญญัติคุ้มครองผู้บริโภคและกฎหมายโฆษณาห้ามการเคลมผลลัพธ์เกินจริง
   - **มาตรการป้องกัน:**
     - System Prompt ของ DeepSeek กำหนดห้ามอ้างสรรพคุณทางการแพทย์ ห้ามคำว่า "หายขาด 100%", "ขาวถาวร", "การันตีผล"
     - ระบบมี Blacklist Filter ตรวจสอบคำต้องห้ามซ้ำอีกชั้นหลังได้รับคำตอบจาก AI
2. **ความเพี้ยนของตัวอักษรไทยบนป้าย A4:**
   - **ข้อกำหนด:** โมเดล Image/Video AI มีข้อจำกัดในการวาดภาษาไทย อาจเกิดสระลอย หรือตัวหนังสือผิด
   - **มาตรการป้องกัน:**
     - หน้า Review แสดงภาพเฟรมที่เห็นป้ายชัดเจน ให้ผู้ใช้เป็นผู้ตรวจสอบและกดอนุมัติด้วยตนเอง

## 3. ความปลอดภัยของข้อมูลส่วนบุคคลและสิทธิ์ระบบ (Security & Privacy)

1. **การจัดเก็บ API Key:**
   - DeepSeek API Key เก็บเฉพาะใน `chrome.storage.local` บนเครื่องผู้ใช้เท่านั้น ไม่ส่งออกภายนอกเด็ดขาด
2. **การจัดการ Session Cookie:**
   - Cookie ของ TikTok ถูกใช้งานผ่าน Context ภายใน Extension เท่านั้น ห้ามพิมพ์ลงใน Console Log, ห้ามแสดงบน UI, และห้ามรวมอยู่ใน Debug Bundle
3. **การขอสิทธิ์ใน Manifest V3 (Principle of Least Privilege):**
   - ตัดสิทธิ์ `debugger` ที่ไม่จำเป็นออก ใช้ DOM Automation มาตรฐาน
   - ระบุ `host_permissions` เฉพาะโดเมนที่เกี่ยวข้องเท่านั้น (`*.tiktok.com`, `meta.ai`, `labs.google`, `api.deepseek.com`)
   - นโยบาย CSP เข้มงวด ไม่อนุญาต `eval` ภายนอก และไม่โหลดไลบรารีจาก CDN ภายนอก
