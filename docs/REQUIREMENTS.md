# ข้อกำหนดความต้องการของระบบ (System Requirements Specification)
**โครงการ:** RUAYRUAY GROUP — TikTok Affiliate Showcase & Auto-Video Studio (Extension V2)  
**สถานะ:** รอผู้ใช้งานยืนยัน (Awaiting User Confirmation)  
**วันที่บันทึก:** 2026-10-29  

---

## 1. สิ่งที่ตกลงร่วมกัน (Agreed Specifications)

### 1.1 ผู้ใช้และการติดตั้ง (User & Environment)
- **ระบบปฏิบัติการและเบราว์เซอร์:** Windows 10/11, Google Chrome ล่าสุด (สถาปัตยกรรม Chrome Extension Manifest V3)
- **รูปแบบการใช้งาน:** ใช้งานเครื่องเดียวสำหรับผู้ใช้โดยตรง (Single User Workstation)
- **การตัดสิทธิ์ที่ไม่จำเป็น:** ไม่ใช้ระบบ License Server, Device ID, PIN, Critical Job Token เดิม และไม่ฝัง API Key / Cookie ลงในโค้ดหรือ Git repository

### 1.2 แหล่งข้อมูลสินค้า (Showcase API Integration)
- **การเชื่อมต่อ:** ผู้ใช้ล็อกอิน TikTok บน Chrome เบราว์เซอร์ปกติ แล้ว Extension เรียก Showcase API จากภายในโดยส่ง Session Cookie อัตโนมัติ (`fetch` พร้อม `credentials: "include"`)
- **API Endpoint:** `https://shop.tiktok.com/api/v1/streamer_desktop/showcase_product/list`
- **การจัดการข้อมูล:** รองรับการดึงแบบแบ่งหน้า (Pagination ด้วย `offset` และ `count`), Rate-limiting backoff, จัดการ Session หมดอายุ (HTTP 401/403) และแคชข้อมูลลงฐานข้อมูลเครื่องผู้ใช้
- **ฟิลด์สินค้าที่จัดเก็บ:** `product_id`, `title`, `price`, `cover_url`, `images[]`, `stock`, `commission`, `category`, `shop_name`, `updated_at`

### 1.3 การคิดคอนเทนต์และบทพูด (DeepSeek API)
- **บทบาทของ DeepSeek:** คิดแคปชัน, แฮชแท็ก, บทพูดภาษาไทย (Voiceover) 1 ชุดต่อเนื่องต่อคลิป, CTA, และข้อเสนอข้อความบนป้าย (ไม่ใช้ DeepSeek เขียนภาพหรือคิด Storyboard ภาพ)
- **รูปแบบ Output:** บังคับโครงสร้างเป็น JSON Schema เสมอ และตรวจ Validate ทุกครั้ง
- **ความเร็วและจังหวะเสียงพากย์:** กำหนดเพดานความเร็วเริ่มต้น 11 ตัวอักษรภาษาไทยต่อวินาที เพื่อให้บทพูดจบพอดีกับความยาววิดีโอ (Flow 8 วินาที ≈ ไม่เกิน 88 ตัวอักษร, Meta AI 10 วินาที ≈ ไม่เกิน 110 ตัวอักษร)
- **แคปชันสำรอง (Fallback Caption):** ใช้ชื่อสินค้าจาก Showcase ผสมคลังแฮชแท็ก 10–20 รายการ พร้อมติดป้าย "ใช้แคปชันสำรอง" ในหน้า Review หาก DeepSeek ขัดข้อง

### 1.4 โหมดวิดีโอและ Prompt Template
- **โหมดเดียวที่เปิดใช้งาน:** "โหมดเห็นแค่มือถือสินค้า" (Hands-Holding Product ในฉากโกดังสต็อกสินค้าชัดลึก)
- **โครงสร้าง Prompt:** ล็อกตามภาคผนวกเป๊ะ ตัวต่อตัวอักษร
  - **ภาคผนวก A:** ภาพนิ่งสำหรับ Flow (`image-prompt.txt`)
  - **ภาคผนวก B:** วิดีโอ 8 วินาทีสำหรับ Flow (`flow-video-prompt.txt`)
  - **ภาคผนวก C:** วิดีโอตรง 10 วินาทีสำหรับ Meta AI (`meta-video-prompt.txt`)
- **การแทนที่ตัวแปร:** `{{SIGN_TEXT}}`, `{{PRODUCT_NAME}}`, `{{VOICEOVER_TEXT}}`, `{{DURATION_SECONDS}}`, `{{VOICE_BLOCK}}` ตรวจสอบความถูกต้องและป้องกันไม่ให้มีแท็กหลุดค้าง
- **เครื่องมือสร้างวิดีโอ:**
  - **Meta AI (หลัก):** สร้างวิดีโอตรง 10s หรือ 20s (สร้าง 2 คลิปแล้วต่อกัน)
  - **Google Flow (รอง/สำรอง):** สร้างภาพนิ่งก่อนด้วย A แล้วสร้างวิดีโอ 8s ด้วย B
- **การรวมคลิปและตัดต่อ:** ใช้ `ffmpeg.wasm` (`merge-v3.js` + `ffmpeg-merge-worker.js`) รวมคลิปและตรวจ QC (ความยาว ≥ 9.5s, สัดส่วน 9:16, ไม่เป็นภาพนิ่ง/ดำ, เสียงครบ)

### 1.5 การโพสต์และจัดการ TikTok Studio
- **การปักตะกร้า:** ค้นหาด้วยตัวเลข `product_id` ในไดอะล็อกของ TikTok Studio และมีระบบตรวจจับ Rejection ("Couldn't add product link") เพื่อหยุดงานทันทีก่อนกดโพสต์
- **โหมดการโพสต์:**
  - **โหมด A (Review Mode - ค่าเริ่มต้น):** คลิปที่ผ่าน QC ต้องรอผู้ใช้อนุมัติในหน้า Review ก่อนส่งเข้า TikTok Studio
  - **โหมด B (Auto Mode):** โพสต์อัตโนมัติเมื่อผ่านเกณฑ์นิรภัยครบถ้วน
- **ระบบตั้งเวลา 2 วิธี:**
  - **วิธีที่ 1 (TikTok Studio Native Schedule):** ใช้ฟังก์ชันตั้งเวลาของ TikTok Studio หากเวลาเป้าหมายอยู่ในช่วงที่ระบบรองรับ (ปิดเครื่องหลังตั้งเวลาได้)
  - **วิธีที่ 2 (Internal Queue with Alarms):** Extension ถือคลิปไว้ในคิวแล้วปลุกด้วย `chrome.alarms` เมื่อถึงเวลา (ต้องเปิดเครื่องทิ้งไว้)
- **การติดป้ายเนื้อหา:** บังคับเปิดสวิตช์ "เนื้อหาที่สร้างด้วย AI" (AI-generated content) เป็นค่าเริ่มต้นเสมอ

## 3. สิ่งที่ยังไม่ตัดสินใจ / รอการทดสอบเชิงประจักษ์ (Empirical Tests)

1. **ความยาวสูงสุดของ Prompt ในช่องกรอกของ Meta AI:** ต้องทดสอบระหว่างรัน Phase 4 ว่ารับ Prompt ฉบับเต็มในภาคผนวก C ได้ครบทุกตัวอักษรหรือไม่ หรือจำเป็นต้องมีเวอร์ชันย่อส่วนขยาย
2. **ความถูกต้องของตัวหนังสือภาษาไทยบนป้าย A4:** โมเดลภาพมักวาดอักษรไทยเพี้ยน จึงต้องพึ่งพาหน้า Review ให้ผู้ใช้ตรวจเช็กเฟรมป้ายเป็นหลัก
3. **ขอบเขตการตั้งเวลาของ TikTok Studio จริง:** ตรวจสอบช่วงเวลาล่วงหน้าขั้นต่ำ (เช่น 15 นาที) และสูงสุด (เช่น 7–10 วัน) เพื่อนำมาเป็นค่า config ในตัวคำนวณตารางเวลา

## 4. สิ่งที่ไม่ทำในระยะนี้ (Out of Scope for MVP)

- การจัดการหลายบัญชี TikTok พร้อมกัน (โครงสร้างแยกรองรับ แต่ยังไม่เปิดใช้งานใน UI Phase 0–5)
- ระบบ OCR ตรวจสอบความถูกต้องของข้อความบนป้ายโดยอัตโนมัติ
- การโพสต์ไปยัง Facebook Reels หรือ Shopee Video
- การดึงสินค้าจาก Shopee
- โหมด Storyboard หรือโหมดวิดีโอแนวอื่น ๆ (ล็อกเฉพาะโหมดมือถือสินค้าโกดัง)
- ระบบ License Server / ระบบขายสิทธิ์

## 5. เกณฑ์การยอมรับการส่งมอบ (MVP Acceptance Criteria)

ระบบถือว่าเสร็จสิ้นระยะ MVP (Phase 0–5) เมื่อ:
1. ดึงสินค้าจริงจาก Showcase API ผ่าน Session Cookie ได้หลายหน้าพร้อมแคช
2. ส่งข้อมูลสินค้าให้ DeepSeek สร้างแคปชัน แฮชแท็ก และบทพูดที่ถูกต้องตาม JSON schema และคำนวณความเร็วคำพูดได้พอดี
3. นำ Prompt ภาคผนวก C / A+B ส่งให้ Meta AI / Flow สร้างคลิป 9:16 ได้จริงอย่างน้อย 3 สินค้า
4. รวมคลิปและผ่านการตรวจ QC (ความยาว, เสียง, สัดส่วน)
5. แสดงคลิปในหน้า Review ให้ผู้ใช้กดอนุมัติ แก้ไขแคปชัน หรือสั่งสร้างใหม่ได้
6. ส่งโพสต์ขึ้น TikTok Studio สำเร็จ พร้อมปักตะกร้าด้วย `product_id` และกำหนดเวลาตามตาราง
