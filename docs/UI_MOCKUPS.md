## 1. ปรัชญาการออกแบบ: Glassmorphism Design System

1. **ธีม Glassmorphism (Frosted Glass & Ambient Glow):**
   - พื้นหลังไล่เฉดสีลึก Slate-950 ถึง Indigo-950 พร้อม Ambient Light Sphere เบลอ 120–150px
   - การ์ดและพาเนลใช้ `backdrop-filter: blur(16px)` ความโปร่งแสง `rgba(255, 255, 255, 0.06)` เส้นขอบเรืองแสงบาง `rgba(255, 255, 255, 0.12)`
   - ให้ความรู้สึกล้ำสมัย มินิมอล และสบายตา ไม่รกแบบธีม Neon เก่า
2. **การพับเก็บ Sidebar (Collapsible Sidebar Toggle):**
   - มีปุ่ม Toggle `[ ◀ / ▶ ]` บนหัวบาร์มุมซ้ายบน
   - ผู้ใช้สามารถกดเพื่อย่อแถบ Sidebar จากกว้าง 256px (`w-64`) ให้เหลือเฉพาะไอคอน 80px (`w-20`) เพื่อเพิ่มพื้นที่มองเห็นข้อมูลตารางสินค้าและคิวงานได้อย่างเต็มตา
3. **สถานะแบบ Multi-signal Status:**
   - ใช้ทั้งไอคอน จุดสถานะเรืองแสง และข้อความภาษาไทยกำกับชัดเจน (🟢 พร้อมทำงาน, 🟡 กำลังเรนเดอร์, 🔴 รอการอนุมัติ)
